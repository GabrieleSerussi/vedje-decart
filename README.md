# VEDJE project page (Decart Research)

Decart Research version of the project page of *VEDJE: Video-Efficient Discriminative Joint Encoder for Scalable Video-Text Retrieval*, published at https://gabrieleserussi.github.io/vedje-decart/.

The code, the Colab notebook and the classic version of the page are in [GabrieleSerussi/vedje](https://github.com/GabrieleSerussi/vedje). This repository only hosts the page; it is generated from the page source with `configure.py --decart-deploy` and served by GitHub Pages from `main`, root folder.

The brand fonts and textures under `assets/` are Decart's and are not covered by an open license.
